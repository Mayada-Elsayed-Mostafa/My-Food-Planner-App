# 🍽️ Food Planner App

An Android app to help users plan meals weekly using TheMealDB API. Users can search recipes, view details, and save favorites offline.

## ✨ Features
- Search meals by category, area, or ingredient
- View meal details, instructions, and video
- Add meals to favorites (Room DB support)
- Firebase authentication (Login/Signup)

## 🛠️ Tech Stack
- Kotlin, Jetpack Compose
- MVVM, Repository Pattern
- Retrofit, Room, Firebase Auth
- RxJava for reactive programming
